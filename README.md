# Mark Jay Lisay — Animated Portfolio

Personal portfolio for **Mark Jay Lisay**, hosted with GitHub Pages.

## Live site

https://anamesyaj.github.io

## Architecture

- Dependency-free HTML/CSS/JavaScript
- Responsive layout
- Canvas ambient particles
- Scroll-triggered reveals
- Animated counters
- Pointer-reactive project cards
- Reduced-motion accessibility support

## Deployment

The repository is the source of truth for the public portfolio. GitHub Pages serves the site from this repository.

Changes committed to the publishing source update the live portfolio automatically.
